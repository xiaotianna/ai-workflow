# AI Workflow 文档

欢迎来到 AI Workflow 文档。这里集中介绍工作流的创建、配置、测试和发布方式。

## 快速开始

你可以通过下面三个步骤开始使用：

1. 在工作室中新建工作流应用。
2. 添加所需节点并完成节点配置。
3. 测试运行通过后发布工作流。

前往[快速开始](/docs/getting-started)查看完整操作流程，或阅读[工作流基础](/docs/workflow-basics)了解核心概念。
