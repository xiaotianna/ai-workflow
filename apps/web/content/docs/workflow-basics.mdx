# 工作流基础

工作流由节点和连线组成。节点负责执行具体任务，连线决定任务之间的执行顺序。

## 节点

每个节点都包含输入、配置和输出。常见节点包括：

- **Start**：声明工作流对外接收的输入。
- **LLM**：调用已配置的大语言模型。
- **HTTP**：请求外部 HTTP 接口。
- **Code**：运行自定义 JavaScript 代码。
- **End**：组织工作流最终输出。

## 变量引用

下游节点可以引用上游节点的输出，也可以使用系统变量和环境变量。引用会随着工作流执行自动解析。

## 草稿与发布

编辑器中的内容属于当前草稿。发布后会生成不可变的版本，API 和子工作流调用始终使用已发布版本。

| 状态   | 用途                   |
| ------ | ---------------------- |
| 草稿   | 编辑、调试和测试运行   |
| 已发布 | API 调用和子工作流调用 |
